# C — Platform & Engineering Validation (TakafulTech build spec)

Validator scope: §2 (DoD, R1–R8), §3, §4, §9 (incl. 9.4 RLS), §10, §11, §12, §13, §14, M00, M01, M24, M26, M27, M29, M30, M31, M32.
Source: `/home/user/erp/README.md` (read in full, lines 1–1160). Date of check: 2026-10-28.
Method: web research (vendor docs, npm registry), package inspection (`npm pack`), and throwaway feasibility tests on a local PostgreSQL 16.15 (scratchpad only, now stopped).

---

## Summary

The stack (Next.js on Vercel fra1, Neon Frankfurt, Drizzle, Better Auth, pg-boss, Playwright PDF) can build this, and most of the choices are current as of Oct 2026. Every package is actively maintained: next 16.4.3, better-auth 1.7.14, @better-auth/passkey 1.7.14, drizzle-orm 0.45.4 (1.0 is at RC), pg-boss 12.38.0, @neondatabase/serverless 1.2.0, temporal-polyfill 1.0.6, next-intl 4.14.9, @signpdf 4.0.0, playwright 1.64.1.

The real risks are not package choices. They are design interactions the README does not settle, plus the schedule:

1. **RLS against system postings.** Fund-scoped RLS breaks automatic cross-fund postings, the deferred per-fund balance trigger, the audit chain and the number series. A privileged "system context" design is missing.
2. **Hash-chain throughput.** A synchronous global hash chain serialises every write in the database, batch jobs included.
3. **PAdES.** The "signature validates" acceptance test depends on a certificate provider that has not been chosen (Q32) and on the legal recognition of e-signatures under Libyan Law 6/2022. Node PAdES libraries only cover the basic B-B level.
4. **Undecided infra.** The worker host (ECS vs Fly.io), the secrets vault and the per-environment topology are open, yet the tenant factory is scheduled for days 1–2.
5. **"i" content workload.** An estimated 3,000–5,000 Phase 1 keys must be approved in two languages, with a 5-day review sprint.
6. **Wrong article citation.** Law 6/2022 is the *Electronic Transactions* law (data protection is Chapter 7, Arts. 73–79). Transfers abroad are **Art. 78**, not "Arts. 73–77".
7. **No multi-agent conventions.** Migration ordering, Drizzle schema ownership and shared registries are undefined, so parallel lanes will collide.

Total flags: 2 BLOCKER, 11 HIGH, 15 MEDIUM, 8 LOW.
